# Nova Lab — Banking Admin Panel

Samira's current project, since 2025. She works as a frontend developer at Nova Lab on a large administration platform for bank operators. Bank staff use it to manage financial services, digital lending and daily operational work.

## What Samira builds there

- The platform frontend, with Next.js and TypeScript.
- Reusable data components: configurable data grids with server-side sorting, filtering and paging, dynamic schemas, and Excel export. These grids stay fast with large data sets because the heavy work happens on the server.
- Generated code: API clients, React Query hooks and form validation are generated from the OpenAPI specs. This removes hand-written boilerplate and keeps the frontend in sync with the backend.
- File management for the platform, built on MinIO-based storage.

She works with cross-functional teams on secure software for banking and digital lending operations.
