# What Samira Builds — Scope and Stack

## Scope

Samira builds the software people use all day at work: admin panels, dashboards, back-offices and data-heavy web apps.

She also accepts marketing sites and landing pages when they are useful, but they are not the focus of her work.

## Why this kind of software

Every project in her work history is a tool someone uses for hours — a bank operator, a postal clerk, a sales manager. When that tool is slow or confusing, the cost is real: errors, delays and overtime. Samira's work is to make those screens fast, clear and hard to get wrong.

Her goal is to be the developer teams call when their internal tools slow the business down — and to show that "boring" software can be the best-built software in a company.

## Main stack

- React, Next.js, TypeScript
- React Query, React Hook Form
- MUI, Tailwind CSS
- Data grids: AG Grid and custom grids with server-side operations

## Other tools she has used

Redux and Redux Toolkit, Context API, Vue.js, Formik, Yup, ApexCharts, styled-components, SASS, CSS Modules, Strapi, Figma, Git, Jira, Trello. She works in Agile (Scrum) teams.

## What "done" means in her work

- Fast with real data volumes, not ten sample rows.
- Clear forms that stop wrong entries.
- Every empty, loading and error state handled.
- Clean, typed, reusable code the next developer can take over.
